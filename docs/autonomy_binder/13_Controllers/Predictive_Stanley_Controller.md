# Predictive Stanley Controller

The `PredictiveStanleyController` (`src/algorithms/controllers/PredictiveStanleyController.h`) is an advanced lateral controller used for accurate path tracking.

## Purpose vs PID
While a simple PID controller is excellent at pointing the rover at a single distant waypoint, it struggles to keep the rover *exactly* on a complex, curving path generated by the A* algorithm (especially at high speeds).

The Stanley Controller calculates a steering command that minimizes both the **heading error** (the angle between the rover and the path) AND the **cross-track error** (the perpendicular distance from the center of the rover to the nearest point on the path).

## Predictive Control

Because the Mars Rover has significant mass and skid-steer kinematics, it cannot change direction instantaneously. To account for this, the `PredictiveStanleyController` utilizes a **Prediction Horizon**.

1. **Unicycle Model**: Using `src/algorithms/kinematics/UnicycleModel.hpp`, the controller takes the rover's current velocity and heading and mathematically predicts where the rover *will be* several timesteps in the future (`nPredictionHorizon`).
2. **Error Calculation**: Instead of calculating the cross-track error based on where the rover is *right now*, it calculates the error based on where the rover is *going to be*.
3. **Output**: It returns a `DriveVector` containing the optimal `dThetaHeading` and `dVelocity` to gracefully intercept and ride the path.

## Key Tuning Parameters

- **Control Gain (`STANLEY_CROSSTRACK_CONTROL_GAIN`)**: Defines how aggressively the rover attempts to correct its cross-track error.
  - *If increased*: The rover will snap violently back to the path if it drifts off.
  - *If decreased*: The rover will take a lazy, smooth curve back toward the path.
- **Angular Velocity Limit (`STANLEY_ANGULAR_VELOCITY_LIMIT`)**: Caps the maximum turning rate the controller can command, preventing the skid-steer kinematics from losing traction.
- **Prediction Horizon / Time Step**: Defines how many steps into the future, and how large each step is, that the Unicycle Model evaluates.

## Usage
The `PredictiveStanleyController` is given a `std::vector<geoops::Waypoint>` reference path (usually the output of the A* planner).
On each tick of the state machine, it is called:
```cpp
PredictiveStanleyController::DriveVector vector = m_StanleyController.Calculate(stCurrentRoverPose, maxSpeed);
```
The resulting `DriveVector.dThetaHeading` is then usually passed into the `DriveBoard` kinematics (which internally uses a PID controller) to actually actuate the motors to hit that heading.
